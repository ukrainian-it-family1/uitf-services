# UITF: розділ «Послуги»

Чотири нові сторінки для ukrainian-it.family: три сторінки послуг і форма заявки. Українською та англійською.

| Папка | Що всередині | Для кого |
|---|---|---|
| [`preview/`](preview/) | Перегляд розділу, щоб погодити сторінки. Як відкрити: [`preview/README.md`](preview/README.md) | Погодження |
| [`frontend/`](frontend/) | Код для сайту: сторінки Vue (Inertia), компоненти, переклади EN/UK, маршрути, зміни даних, дизайн-система сайту. Інструкція: [`frontend/README.md`](frontend/README.md) | Розробники |
| [`services/`](services/) | Контент-план і тексти сторінок, з яких зроблено код | Довідка |

**Перегляд онлайн:** https://ukrainian-it-family1.github.io/uitf-services/

Як переглядати і надсилати правки: [ІНСТРУКЦІЯ.md](ІНСТРУКЦІЯ.md).

Перегляд оновлюється автоматично після кожного пушу в `main` (GitHub Actions → Pages). Запустити локально:

```bash
cd preview && npm install && npm run dev
```

Потім відкрийте http://localhost:5180.

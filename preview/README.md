# Попередній перегляд розділу «Послуги»

Тут можна відкрити нові сторінки розділу «Послуги» і погодити їх до того, як вони з'являться на ukrainian-it.family.

Перегляд показує весь розділ, українською та англійською:

| Сторінка | Статус |
|---|---|
| Операційні платформи | нова |
| Регульовані продукти | нова |
| Аудит і перезапуск | нова |
| Форма заявки | нова |
| Послуги | як на сайті, картки ведуть на нові сторінки |
| Розробка продукту | без змін, для контексту |

## Як відкрити

Найпростіше відкрити посилання: **https://ukrainian-it-family1.github.io/uitf-services/**. Покрокова інструкція для тих, хто не працює з кодом: [`../ІНСТРУКЦІЯ.md`](../ІНСТРУКЦІЯ.md).

Локально:

Потрібен Node.js 22 або новіший.

```bash
cd preview
npm install
npm run dev
```

Відкрийте http://localhost:5180. Стартова сторінка містить список усіх сторінок з посиланнями українською та англійською. На кожній сторінці вгорі є плашка «Попередній перегляд» і посилання назад до списку.

### Статична версія

```bash
npm run build     # збирає перегляд у папку dist/
npm run preview   # відкриває зібрану версію на http://localhost:5180
```

Папку `dist/` можна викласти на будь-який статичний хостинг з підтримкою SPA (Netlify, Vercel, Cloudflare Pages). Усі шляхи мають вести на `index.html`.

## Чим перегляд відрізняється від сайту

- Шапка, футер і спільні блоки сайту відтворені за кодом живого сайту, тільки для перегляду.
- Форма нічого не надсилає.
- Кейси, тексти «Чому ми», кроки процесу і стек взяті з живого сайту станом на 1 жовтня 2026. Зображення завантажуються з ukrainian-it.family.
- Посилання поза розділом «Послуги» (кейси, блог, про нас) відкриваються на живому сайті.

## Код для сайту

Код для інтеграції лежить у папці [`../frontend`](../frontend). Інструкцію для розробників англійською див. у [`../frontend/README.md`](../frontend/README.md). Код із цієї папки (`preview/`) переносити на сайт не потрібно.
